# ChoralRoot: presets per engine (docs/PRESETS.md; design/choralroot-fm1-preset-screens.png). tools/emu/test_cr.sh reads
# the "popup:", "sound:", "engine pick:" and "save:" lines.
# 1. PRESETS turns inside the chord part's engine's pool only, INIT at 00, wrapping: from TINE EP (FM6 01) -1: 00 INIT,
#    -1: 25 PIANO (the end), +6: 05 FM PAD ("05" / "FM PAD" / "FM6 . 05/25": the pool's 25 presets, INIT not counted).
#    The meter: a stripe per preset, none lit on INIT, 25 of 25 on PIANO, 5 on FM PAD.
# 2. OPT held + PRESETS +2 (past FM TONE): the engine picker (VA, "25 presets"); OPT released: VA 01 LUSH PAD; PRESETS +3: VA 04; OPT +
#    PRESETS -1: FM6, back on 05 FM PAD (remembered per engine); +1: the VA, back on 04; -1: FM6 05 again.
# 3. SAVE on FM PAD (factory, not edited): the dialog, Save as new by default; OCT+: the naming screen (FM6 26, the
#    pool's next place); A D G, OCT+: U01, FM6 26; PRESETS -1 +1: 25 PIANO, 26 ADG (the pool has 26 presets now).
# 4. PRESETS +3: 02 FM BELL; SAVE, SELECT -1: Overwrite, OCT+: a record bound to FM BELL (U02), the number and the
#    name kept; PRESETS +1 -1: 02 FM BELL with the mark.
# 5. SAVE, SAVE held 1 s: "reset to factory?", OCT+: U02 deleted, the factory FM BELL back at 02 (no mark).
# 6. 127 Saves as new fill the 128 slots (0.22: the sound pool); the next one: "no free slot". (The first of them from the factory FM BELL: the
#    dialog's default; the others from the user preset just saved: Overwrite by default, SELECT +1: Save as new. Until
#    the SAVE menu took the Options' grammar, 3y42, these turns were KNOB 1's: it changes values now, SELECT the entry.)
# 7. FM6's pool is 153 presets long now, its meter 32 stripes: PRESETS +1: 00 INIT (none lit), +1: 01 (one), -2: 153,
#    the last (every one), -1: 152 (31: all of them only on the last).
