# Each "harm: .." log line is the chord you are on, home, and the eleven white keys left to right (* = goes home).
#  1. C major (MAJ + C5) struck and released; LATCH held: the mode, home C major (the chord on screen), shot
#  2. D4 (the most restful place) held 400 ms: its chord sounds while the key is down, released: silence
#  3. G5 (the hardest pull) 400 ms, then D#4 (a black key: the chord of the white key left of it, richer) 400 ms
#  4. LATCH tapped (Sticky on): A4 tapped 50 ms: latched, it sounds on; LATCH tapped (Sticky off: it ends)
#  5. REC, F4 500 ms, C5 500 ms, REC: the loop plays the two map chords back (3 s), LOOP tapped: it stops
#  6. OCT+: the chord you are on is home, the layer stays (shot)
#  7. MIN held + E4: E minor as ever (a chord key held: the player's own chord), the map follows it
#  8. KEY tapped: Key Mode on (C major) is home at once; KEY tapped again: Key Mode off, home stays C major
#  9. OCT-: the mode ends; C5 alone plays its single note as ever (no chord key, Key Mode off)
