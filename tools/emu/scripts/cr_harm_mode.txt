# cr_key_chord). Key Mode off. Each "harm: .." log line is the chord you are on, home, and the eleven white keys.
#  1. C major (MAJ + C5) struck and released; LATCH held: the mode, home C major (the chord on screen), shot
#  2. D4 held 400 ms: Cmaj9 (Colour voicing) while the key is down; released: silence

#  4. G#4 (a black key: A9, the approach chord into Dm9 on A4) 400 ms
#  5. LATCH tapped (Sticky on): D4 tapped, then E4 tapped: Am9 replaces Cmaj9, the two notes they share ring on (3
#     note-ons, not 5); LATCH tapped (Sticky off: it ends)
#  6. KNOB 1 -1 (7ths): D4 is Cmaj7; KNOB 1 -1 (triads): D4 is C; KNOB 1 +2 (9ths again); KNOB 2 -2 (Shell): D4 is
#     C3 B3 E4; KNOB 2 +2 (Colour again)
#  7. REC, F4 500 ms, C5 500 ms, REC: the loop plays the two chords back (3 s), LOOP tapped: it stops
#  8. OCT+: the chord you are on (Abmaj9, C5's) is home (shot)
#  9. MIN held + E4: E minor as ever (a chord key held: the player's own chord)
# 10. KEY tapped: Key Mode on (C major) is home at once; KEY tapped again: Key Mode off, home stays C major
# 11. OCT-: the mode ends; C5 alone plays its single note as ever (no chord key, Key Mode off)
