# ChoralRoot 0.18: the loop editor while its loop plays, Transpose, the voicing's snap (the owner, 2026-10-11; docs/LOOPER.md
# "The loop editor"). Chord keys: MAJ = A#3, MIN = G#3; LATCH = the LFO button; LOCK = B3.
# A. SEQ on the view: the editor on an empty slot (16 steps). D E G A (MAJ) into steps 1 5 9 13. Stopped: the name line
#    is the selected step's (A), no playing name.
# B. LOOP: it plays. Step 15 (empty): MIN + C5 held 700 ms over the loop's chords, let go: step 15 is Cm ALONE (none of
#    the loop's own chords: a loop voice never reaches the editor).
# C. LATCH on. Step 3: MAJ + F4, let go: the chord sounds on (latched) and IS in step 3 now (before: not until the next
#    press). Step 7 (empty), no key down, the latched F still sounding over the loop: the name line reads "-", the
#    selected step, in every frame (before: F between the loop's notes). MIN + B4 down: the name line reads Bm while the
#    key is down. Let go: step 7 is Bm alone (before: F, the chord that was still sounding). LATCH off: nothing written.
# D. Two seconds of playback: the playing name at the left of the page's name: D, E, G, A (and what was entered), never
#    empty once the loop has struck; SELECT +1: page 2 "Trig": the same. LOOP: stopped: no playing name.
# E. Trig, step 1 (D): KNOB 4 +1: D#, the cell hot "+1" (shot), then "D#4" (shot); -3: C. Step 2 (empty): nothing.
#    Step 1: +70 in one turn: as far as it goes (127); +1: refused ("no higher"); -67: C again.
# F. GLO held + KNOB 3: Follow -> 0 -> Follow -> (the other way) 0; a value set by hand (+3), GLO + ALGORITHM -1: Follow;
#    (-8), GLO + ALGORITHM +2: 0, one snap for the turn. No bass level popup (GLO + ALGORITHM outside the editor).
#    SELECT -1: page 1: GLO + ALGORITHM +1: "step voicing: Follow".
# G. LOCK (B3) with MIN latched: E5 alone into step 2: Em, one chord; F5 into step 4: Fm. LOCK off.
