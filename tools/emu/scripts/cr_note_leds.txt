# ChoralRoot: a sounding note lights every root key of its note name (the owner, 2026-10-11): a chord voiced, transposed
# or shifted out of the keys' two octaves (D4..G5) still shows, on both octaves' keys; never a chord key. The dump's
# "key leds:" line: F3..C4 (the chord keys and B3), then D4..G5: 0 off 1 faint 2 dim 3 mid 4 lit. tools/emu/test_cr.sh
# reads the dumps by number.
keys classic                  # (0.25.1: FM-1 is the default; this script was written for the Classic chord keys)
wait 300
btn A#3 down                  # MAJ + D4: D major (62 66 69)
wait 60
btn D4 down
wait 400
expect led D4 on
expect led F#4 on
expect led A4 on

expect led F#5 on
expect led E4 off
expect led G5 off
expect led A#3 on             # MAJ, held: its own state
expect led C4 faint           # the other chord keys and B3: idle (no note name lights them)
expect led F3 faint
expect led B3 faint

expect led F#5 on
expect led E4 off

expect led F#4 on
