# ChoralRoot: the PLAY menu's knob row, two pages (docs/LOOPER-MODES.md; CR_K_LOOPMENU; 0.18). LOOP (PLAY) held and
# released locks it open, stopped. Page 1: Length / Rate / Quantize / Count-in under the slot strip, the mode and the
# length; KNOB 1..4: each cell hot, no popup. SELECT +1: page 2: Level (KNOB 1) and Metronome (KNOB 2: on, then off again), the bottom line "2/2"; SELECT
# -1: page 1. OCT-. Then a 1-bar loop is recorded (REC, D, REC) and plays; LOOP held: the menu, the timeline in the
# middle, the dial in the top line, no ring; page 2, KNOB 1: Level hot; OCT- closes it.
